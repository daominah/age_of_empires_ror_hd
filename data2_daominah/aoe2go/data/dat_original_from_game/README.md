# Original AoE2 DE data files

Copied unedited from the Steam install, keeping the game's folder layout.
Together they describe all units, buildings, technologies
and each civilization's Technology Tree:

- `resources/_common/dat/empires2_x2_p1.dat`: stats of every unit, building and technology.
- `resources/_common/dat/CivTechTrees/`: one JSON per civilization,
  its available units, buildings and technologies.
- `resources/_common/dat/civilizations.json`: civilization names and info.
- `resources/en/strings/key-value/`: English names and descriptions, by string ID.

Source and version:

- **Source path:** `steamapps\common\AoE2DE\resources\`
- **Patch note:** [Age of Empires II: Definitive Edition – Update 188329](
  https://www.ageofempires.com/news/age-of-empires-ii-definitive-edition-update-188329/),
  published 2026-10-27
- **Date:** the dat and the English strings were last modified on 2026-10-28,
  the day after the patch; the other files are unchanged since 2026-09-23
