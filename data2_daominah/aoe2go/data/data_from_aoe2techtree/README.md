# AoE2 DE tech tree data

Downloaded on 2026-11-03 from the [aoe2techtree](https://github.com/SiegeEngineers/aoe2techtree) repo,
the data behind [aoe2techtree.net](https://aoe2techtree.net),
generated by its maintainers from the official DE `.dat` (up to DE Update 188329):

- [data.json](https://raw.githubusercontent.com/SiegeEngineers/aoe2techtree/master/data/data.json):
  each civ's available techs, units and buildings as ID lists (`civs.{civ}.Tech`),
  and the stats of every tech, unit and building (`data.Tech`).
- [strings.json](https://raw.githubusercontent.com/SiegeEngineers/aoe2techtree/master/data/locales/en/strings.json):
  English names; a tech name is at key `LanguageNameId + 10000`.

To refresh both files from the latest upstream, run `./download.sh`.

## Generate it yourself

Only needed if upstream lags behind a game update.
Upstream makes these files with
[scripts/generateDataFiles.py](https://github.com/SiegeEngineers/aoe2techtree/blob/master/scripts/generateDataFiles.py),
which reads the `.dat` with the Python library `genieutils-py`.
Its inputs are the game files in [../dat_original_from_game](../dat_original_from_game)
(refresh them from the game first):

```sh
# clone outside this repo
git clone https://github.com/SiegeEngineers/aoe2techtree.git
cd aoe2techtree
python -m venv venv
source venv/Scripts/activate   # Git Bash on Windows
pip install genieutils-py
# only English strings are copied: set LANGUAGES = ['en'] in the script first
python scripts/generateDataFiles.py D:/age_of_empires_ror_hd/data2_daominah/aoe2go/data/dat_original_from_game/
```

The output is `data/data.json` and `data/locales/en/strings.json` in the clone.
