# AoE2 DE Hotkeys

My hotkey profile `AoE1Like` compared to the game preset "Classic Hotkeys".
The rows list bindings that differ from the preset "Definitive" (the game default).

- **Profile files**: `profile/AoE1Like.hkp` and `profile/AoE1Like/Base.hkp`
  in `%USERPROFILE%\Games\Age of Empires 2 DE\{SteamID}`.
- **Preset bindings**: `resources/_common/dat/hotkeys.json` in the game install folder,
  entries named `classic` and `definitive`.
