# How to use AoE2DE mods

Just copy the mod dir to your AoE2DE profile mods folder and start the game,
local mods will be enabled automatically.

And before start a Single-player Skirmish game,
change the `Game Settings` > `Data Mods` > choose the copied mod from the list.

Probably the path is like this:

```
%USERPROFILE%\Games\Age of Empires 2 DE\{your_Steam_ID}\mods\local
```
